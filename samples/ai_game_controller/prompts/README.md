# Prompts

## Mục đích

Chứa prompt được version-control và tách khỏi code Python.

## File trực tiếp

- `system_prompt.md`: system prompt dùng chung cho mọi AI provider/model.
- `README.md`: mô tả cách tổ chức prompt và dẫn tới nhóm prompt con.

## Thư mục con

- [`system/`](system/README.md): system prompt chung và quy tắc xử lý event.

Scenario prompt do người dùng tạo sẽ được lưu dưới dạng configuration, không ghi đè system prompt.
