# MCP servers

## Mục đích

Chứa các MCP server chỉ thuộc mini app mẫu. Keyboard và Process MCP server hiện có của project được tái sử dụng, không sao chép vào đây.

## File trực tiếp dự kiến

- `README.md`: mô tả phạm vi MCP của sample và dẫn tới từng server con.

## Server con

- [`game_state/`](game_state/README.md): sở hữu OCR worker, game state và game event.

Chi tiết tool và file triển khai của Game State server được mô tả trong README của chính thư mục đó.
